# Security policy

Thank you for helping keep Meevra Code and its users safe.

## Reporting a vulnerability

**Please do not report security problems in a public issue.**

Send a private report by email to **[founder@meevra.si](mailto:founder@meevra.si)** with the subject line starting with `Security:`. Please include:

- the Meevra Code version (shown in **Settings › Updates**) and your Windows version;
- what the problem is and what an attacker could do with it;
- the steps to reproduce it, or a proof of concept;
- any logs or screenshots that help, with API keys, passwords and personal data removed.

What you can expect:

- an acknowledgement of your report, normally within a few working days;
- a private conversation while we investigate and fix it, and a note when the fix is released;
- credit for the finding in the release notes, if you would like it.

Please give us a reasonable time to release a fix before you disclose the problem publicly, and do not access, change or delete data that is not yours while you investigate.

## Supported versions

Meevra Code is in Public Preview. Security fixes are made in the **latest preview release** only. An installed Meevra Code updates itself through **Settings › Updates**; please update before you report a problem, in case it is already fixed.

| Version | Supported |
|---|---|
| Latest Public Preview release | Yes |
| Any older release | No |

## Scope

In scope: the Meevra Code desktop app, its installer, and its update channel.

Out of scope: the services of third-party AI providers you connect to Meevra Code (please report those to the provider), and problems that need an attacker who already has full control of your computer or your Windows account.
